# xtts-rs — portfolio

**Coqui XTTS-v2 voices from one binary and one 276 MB file: first audio in 35 ms, 13x real time, 1 GB of VRAM.**

- **Goal**: make XTTS-v2 a self-hosted, dependency-free speech engine: no
  Python or PyTorch, one GGUF model file, output identical to the reference,
  as little VRAM and latency as the GPU allows.
- **Target users**: developers adding a French or English voice to
  applications and assistants, administrators of a zallama instance.
- **Context**: a building block of the Ze Family of self-hosted tools,
  hosted by zallama next to pocket-tts, parakeet (speech recognition) and
  the tn normalizer on the same GPU.

Demo (generated by `xtts speak` from the q4k GGUF, RTX 4090):
[demo-fr.wav](demo-fr.wav) (Ana Florence) · [demo-en.wav](demo-en.wav) (Claribel Dervla)

![Pipeline architecture diagram](architecture-diagram.svg)

## Usage scenarios

1. **Voice for an assistant**: zallama's `/v1/realtime` streams each reply
   phrase from `/stream`; the first audio is ready ~35 ms after the phrase.
2. **OpenAI-compatible TTS**: any OpenAI client calls `/v1/audio/speech`
   with one of 58 voices; zallama's normalizer first spells out numbers,
   dates and Markdown.
3. **Batch narration**: `xtts speak -m xtts-v2-q4k.gguf -l fr - < chapter.txt -o chapter.wav`
   splits the text at sentences and writes one WAV.

## Architecture

Rust · candle 0.11 (CUDA / Metal / CPU) · GGUF with a q4k GPT (`QMatMul`) ·
windowed HiFi-GAN streaming · axum HTTP server. Details:
[../docs/architecture.md](../docs/architecture.md), [../AGENTS.md](../AGENTS.md).

## What it does

- French and English speech (12 more XTTS languages through the same code,
  not validated) with 58 built-in voices.
- `xtts convert` packs the Coqui checkpoint into one GGUF (q4k, 276 MB).
- Streaming with the same samples as one-pass decoding (91 dB SNR).
- OpenAI-compatible HTTP server for zallama or any client.

## Results

| | coqui-tts (PyTorch) | this port |
|---|---|---|
| Greedy audio codes | reference | identical |
| Model file | 1.9 GB `model.pth` + vocab + speakers | 276 MB single GGUF |
| VRAM (RTX 4090) | not measured | 776 MiB idle, 1032 MiB peak |
| First audio (streaming) | | 30-45 ms |
| Real-time factor (GPU) | | 13x |
| WER FR / EN (Parakeet ASR) | 1.2 % / 0.5 % (with final period) | 0.6 % / 0.0 % |
