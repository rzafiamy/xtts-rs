xtts-rs is distributed under MPL-2.0. It builds on the work below, each used
under its own license. Versions are those of `Cargo.lock`.

## Authors

- Coqui — XTTS-v2 model, training and Python reference
  ([coqui-ai/TTS](https://github.com/coqui-ai/TTS), MPL-2.0; maintained fork
  [idiap/coqui-ai-TTS](https://github.com/idiap/coqui-ai-TTS), the reference
  used here: coqui-tts 0.27.5). Weights on Hugging Face `coqui/XTTS-v2` under
  the [Coqui Public Model License](https://coqui.ai/cpml) (non-commercial).
- Rija Z. ([@rzafiamy](https://github.com/rzafiamy)) — this port: Rust/Candle
  implementation, GGUF, quantization, streaming, CUDA memory work.
- Developed with the assistance of Claude (Anthropic) through Claude Code.

## Third-party sources

- Weights, `config.json`, `vocab.json` and `speakers_xtts.pth` (the built-in
  voices) come from `coqui/XTTS-v2`; GGUF files converted from them are
  under the CPML too and must credit Coqui.
- `crates/xtts/src/text_tables.rs` is generated by `scripts/gen_text_tables.py`
  from coqui-tts' abbreviation and symbol tables (MPL-2.0).
- No Tauri library is used: xtts-rs is a CLI and HTTP server without a
  graphical interface.
